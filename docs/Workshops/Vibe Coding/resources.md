## The Vibe Coding Stack

### LLMs

- [ChatGPT](https://chatgpt.com) - General-purpose chat model for brainstorming, writing, and coding help
- [Claude](https://claude.ai) - Strong long-context model for coding, writing, and multi-file reasoning

### AI IDEs & Tools

- [Cursor](https://cursor.com) - AI-native code editor for editing real projects with chat and agent tools
- [GitHub Copilot](https://github.com/features/copilot) - AI coding assistant inside your editor and Codespaces
- [Bolt](https://bolt.new) - Browser-based AI builder that scaffolds full apps from prompts
- [Lovable](https://lovable.dev) - AI app builder focused on turning prompts into polished UIs quickly
